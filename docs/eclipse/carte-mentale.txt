 PRINCIPES                                      CE QUE LE SYSTÈME GARANTIT OU NON
════════════════════════════════════════════════════════════════════════════════════════════════════════════

    MÉMOIRE EXTERNE ORGANISÉE
    └── Ce n’est pas une modification des neurones du modèle.

    CACHE LOCAL RAPIDE
    └── Prépare les informations ; ne les rend pas automatiquement connues du modèle.

    ARCHIVES COMPRESSÉES
    └── Réduisent le stockage ; pas les tokens du texte une fois décompressé.

    RÉSUMÉS COURTS
    └── Réduisent le contexte ; les originaux compensent la perte possible de détails.

    RECHERCHE CIBLÉE
    └── Évite de relire tout l’historique ; ne garantit pas une latence nulle.

    BUDGETS LOCAUX
    └── Encadrent les appels ; ne créent pas de points supplémentaires.

    CONNEXION AU FOURNISSEUR
    └── Connexion de base incluse ; architecture API avancée reportée.
